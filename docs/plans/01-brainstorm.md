# Brainstorm — Day 03 · 토론 발언 타이머

> 무인 세션이므로 brainstorming/SKILL.md의 "one question at a time" 흐름 대신 AI 단독 판단으로 MUST / SHOULD / MUST NOT 직접 결정. YAGNI 엄격 적용.

## 사용 시나리오 (1줄 요약)

> 4~6학년 토론 수업 중 교사가 노트북을 TV에 연결, 찬·반 발언이 시작되면 스페이스 키 한 번으로 활성 팀의 누적 시간을 측정. 양 팀 누적 시간 격차를 학생들이 한눈에 보고 균형 잡힌 토론 진행이 가능.

## 꼭 필요한 기능 (MUST)

1. **좌(찬성) / 우(반대) 두 패널의 거대 누적 시간 표시** — TV에서 8m 거리에서도 읽힐 폰트(타이머 글자 최소 20vw). 활성 팀은 강조색, 비활성 팀은 흐림.
2. **스페이스 키 토글로 활성 팀 발언 시작/정지** — 토론 진행 중 양손이 자유롭지 않은 교사 상황. A/L 키로 팀 전환. 마우스 클릭으로도 동일하게 동작.
3. **1인 발언 한도(분:초) 설정 + 초과 시 시각/청각 경고** — 한 명이 1m30s를 넘기면 패널이 amber로 페이드, 2m 한도 초과 시 strong beep + red flash. 한도는 설정 패널에서 조정.
4. **발언 횟수 카운트** — 팀별 "발언 N회" 표시. 활성 팀이 변경되거나 stop 시점에 1 카운트 증가.
5. **리셋(Reset All)** — 확인 모달을 거쳐 양 팀 시간·횟수 0으로 초기화. 우발적 클릭 방지.
6. **풀스크린 모드** — F 키 또는 풀스크린 버튼. Fullscreen API.
7. **시작/종료 비프음 + 음소거 토글** — Web Audio API로 200ms 비프. 짧고 명료하게.

## 있으면 좋은 기능 (SHOULD)

1. **하단 균형 바** — 양 팀 누적 시간 비율을 0~100% 가로 막대로 시각화. 격차가 70%/30%를 넘으면 옅은 경고 색.
2. **설정 영속화** — 팀 이름·1인 한도·음소거 상태를 `localStorage`에 저장. 시간 자체는 휘발성 유지.
3. **현재 발언 경과시간(별도 표기)** — 누적과 분리해 "지금 발언자 경과 mm:ss" 도 작게 표시. 한도 대비 진행률 인지 강화.

## 절대 금지 기능 (MUST NOT — scope creep / 정책 위반)

1. **발언 내용 녹음/저장** — 원본 명세 배제 항목. privacy + 정책상 학교 환경에서 위험.
2. **음성 인식, 발언자 식별** — 명세 배제. AI 호출도 필요 없음 (이 토픽은 Gemini 미사용).
3. **서버 통신·외부 공유·CSV export** — 휘발성 도구. 발언 시간을 영구 저장할 이유 없음. 저장 = 학생 식별 데이터화 위험.
4. **학생 사진/이름 등 개인정보 입력 UI** — 팀 이름만 ("찬성"/"반대" 또는 교사가 정한 토픽 측 라벨) 허용. 학생 개별 이름 입력 X.
5. **다국어 / 다크모드 토글** — TV 환경 한정·한국어 단일·기본 다크. 옵션 토글은 불필요한 복잡성.

## 화면 흐름 (한 화면 SPA)

```
[헤더: 토론 주제 입력(옵션) · 설정 톱니바퀴 · 풀스크린]
[메인: 좌(찬성 누적시간 큰 숫자, 발언 N회, 현재 발언) | 우(반대 동일)]
[하단: 균형 바 · 컨트롤(시작/정지·팀전환·리셋) · 키 안내]
[설정 모달: 팀명 / 1인 한도 / 음소거]
[리셋 확인 모달]
```

## 키보드 매핑 (확정)

| 키 | 동작 |
|---|---|
| `Space` | 활성 팀 발언 시작/정지 토글 |
| `A` | 찬성팀(왼쪽) 활성 + 즉시 시작 (이미 활성이면 무시) |
| `L` | 반대팀(오른쪽) 활성 + 즉시 시작 |
| `F` | 풀스크린 토글 |
| `M` | 음소거 토글 |
| `R` | 리셋(확인 모달 띄우기) |
| `Esc` | 모달 닫기 / 풀스크린 종료(브라우저 표준) |

## 데이터 모델 (in-memory)

```js
{
  pro:  { name: "찬성", elapsedMs: 0, count: 0, currentStartMs: null },
  con:  { name: "반대", elapsedMs: 0, count: 0, currentStartMs: null },
  active: "pro" | "con" | null,
  running: boolean,
  perSpeakerLimitMs: 120000,   // 기본 2분
  warnAt: 0.8,                  // 한도 80%부터 약경고
  muted: false,
  topic: ""                     // 옵션
}
```

localStorage 키: `toron-timer.settings.v1` — `{ proName, conName, perSpeakerLimitMs, muted, topic }` 만 저장. 시간·횟수는 절대 저장하지 않음.
