# Day 03 · 토론 발언 타이머 — 찬·반 누적시계

## 토픽 (100-vibecoding-topics.md #003)

토론 수업에서 찬성·반대팀의 누적 발언 시간을 무대형 풀스크린에 표시. 발언 시간 격차를 시각적으로 드러내 균형 잡기.

## 원본 명세 발췌

- **콘텐츠 주제·목표**: 토론 수업의 찬·반 누적 발언 시간 풀스크린 시각화. 발언 시간 격차를 시각적으로 드러내 균형 잡기.
- **포함 기능**:
  - 좌/우 분할 누적 타이머
  - 발언 횟수 카운트
  - 1인 발언 한도 알림 (예: 2분 초과 시 색 변화)
  - 시작/종료 비프음 (Web Audio)
  - 풀스크린 모드
- **배제 기능**:
  - 발언 내용 녹음·저장
  - 음성 인식, 발언자 식별
  - 외부 공유, 서버 동기화
- **기술 스택**: HTML/CSS/JS, Web Audio API
- **저장 방식**: 휘발성 (세션 종료 시 소멸) + 옵션으로 localStorage에 "마지막 설정값"만 저장 (이름·한도)
- **AI 옵션**: ✕
- **대상**: 4~6학년 · **환경**: TV(전체 시연)
- **DESIGN.md**: **Linear** (키보드·정밀) / 보조: **Vercel** (흑백 정밀)

## 구현 제약 결정

- **스택**: 단일 `index.html` + 자기완비 vanilla CSS + vanilla JS. CDN 의존 0.
- **Gemini**: 미사용. 본 토픽은 자연어 생성이 필요 없는 도구형 앱이다.
- **저장**: 세션 동안 휘발성. 설정(찬·반 팀명, 1인 한도 분·초)만 `localStorage`에 저장하여 다음 수업 재사용 가능.
- **포트**: 로컬 서버 5180 사용 (Tester 환경 표준).
- **목표 환경**: TV 풀스크린 + 교사 키보드/마우스 제어.

## 핵심 의사결정 사항

1. 좌(찬성) / 우(반대) 두 패널의 큰 시각적 분할. 활성 팀만 카운트 진행.
2. **스페이스바**: 활성 팀 발언 시작/종료 토글. **A/L 키**: 찬/반 팀 활성 전환 (스페이스 직전).
3. 1인 발언 한도 초과 시 해당 팀 패널이 경고 색(amber)으로 페이드. 한도의 80% 도달 시 약한 비프, 100% 도달 시 강한 비프.
4. 풀스크린 토글 버튼(`F` 키) — 표준 Fullscreen API.
5. 발언 시작/종료 시 Web Audio API 비프 (200ms, 880Hz/440Hz). 음소거 토글 가능.
6. 데이터 격차 그래프: 화면 하단에 가로 진행률 바로 양 팀 누적시간 비율 표시.
7. 리셋 버튼 — 확인 모달 필수 (실수 방지).
